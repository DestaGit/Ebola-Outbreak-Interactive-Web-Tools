⚠ MODEL NOTE · This is a simplified proportional counterfactual model for educational purposes. It modifies the actual WHO epidemic curve based on the selected parameters using compounding decay after the intervention point. It does not constitute a validated SEIR epidemiological model and should not be used for policy decisions. Real outbreak modelling accounts for incubation periods, heterogeneous mixing, geographic barriers, healthcare capacity constraints, and stochastic effects.
